Curso Básico

Gerência de Configuração de Software

Domine os fundamentos do controle de versão e gestão de configuração para projetos de software

Git

Sobre o Curso

Este curso básico aborda os fundamentos da Gerência de Configuração de Software (SCM) e Controle de Versão, essenciais para o desenvolvimento moderno de software.

Objetivo Principal

Capacitar os participantes com os fundamentos da gerência de configuração de software (SCM) e o controle de versão, apresentando não só os conceitos mas também as principais ferramentas utilizadas no mercado, de modo a desenvolver habilidades práticas e teóricas no tema do curso.

Mercado de Trabalho

Habilidades valorizadas no mercado corporativo

Colaboração

Promove ambiente de trabalho cooperativo

Carreira

Aumenta oportunidades profissionais

Objetivos Específicos

01

Compreensão Conceitual

Entender o conceito de Gerência de Configuração de Software, sua importância e papel dentro do processo de desenvolvimento de software.

02

Controle de Versão

Compreender o processo de Controle de Versão de um projeto e suas aplicações práticas.

03

Habilidades Práticas

Desenvolver habilidades práticas a partir do uso de ferramentas de gerenciamento de repositórios.

Para Quem é Este Curso?

Profissionais de TI

  • Pessoas da área de tecnologia que já programam
  • Desenvolvedores de software
  • Profissionais de tecnologia da informação

Estudantes

  • Alunos de graduação
  • Estudantes de cursos técnicos e profissionalizantes

Transição de Carreira

  • Profissionais de outras áreas com interesse em tecnologia
  • Pessoas que dominam Pensamento Computacional

Pré-requisitos Recomendados

Iniciantes: Curso de Pensamento Computacional
Intermediários: Conhecimento em alguma linguagem de programação (Python, Java, JavaScript, C/C++)

Ementa do Curso

Fundamentos

  • Funcionamento da Gerência de Configuração de Software
  • Conceitos de Controle de Versão
  • Importância do SCM no desenvolvimento

Fluxo de Trabalho

  • Fluxo completo de controle de versão
  • Code Review e Pull Requests
  • Gerenciamento de Issues

Operações com Git

  • Operações básicas de controle de versão
  • Comandos essenciais do Git
  • Boas práticas de commit

Repositórios

  • Integração de repositórios locais e remotos
  • Gerenciamento em servidores externos
  • Plataformas: GitHub, GitLab, etc.

Trilhas Elegíveis

Programação

Essencial para desenvolvedores que precisam versionar código e colaborar em projetos

Engenharia de Software

Fundamental para engenheiros que trabalham com gestão de configuração e qualidade de software

Por Que Fazer Este Curso?

Gestão Eficiente: Aprenda a gerenciar mudanças em projetos de software
Rastreabilidade: Garanta que todas as modificações sejam documentadas
Colaboração: Facilite o trabalho em equipe com ferramentas modernas
Conformidade: Essencial para auditorias em indústrias regulamentadas
